# متجر إلكتروني عربي — GitHub Pages

قالب متجر Mobile First يعمل بالكامل بـ HTML/CSS/JavaScript.

## التشغيل
1. ارفع الملفات إلى Repository في GitHub.
2. من Settings → Pages اختر Deploy from a branch.
3. اختر `main` و`/ (root)`.
4. احفظ وانتظر ظهور رابط GitHub Pages.

## التخصيص
- المنتجات والأسعار والأقسام: `script.js`
- التصميم والألوان: `style.css`
- رقم واتساب: غيّر الرقم الموجود في `script.js` داخل `https://wa.me/...`
- اسم المتجر ومعلومات التواصل: `index.html`

> الصور الحالية تستخدم رموزاً توضيحية حتى يعمل القالب فوراً. يمكن استبدالها بصور منتجات حقيقية لاحقاً.
