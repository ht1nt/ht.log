# متجر إلكتروني + لوحة تحكم (متصلة بـ Firebase)

## الملفات
- `index.html` المتجر
- `admin.html` لوحة التحكم
- `style.css` تصميم المتجر
- `script.js` وظائف المتجر
- `admin.css` تصميم لوحة التحكم
- `admin.js` وظائف لوحة التحكم
- `firebase-config.js` **إعدادات فايربيس (يجب تعديله قبل النشر)**

## المزايا
- المنتجات محفوظة على قاعدة بيانات حقيقية (Firestore) وتظهر لكل الزوار من أي جهاز.
- لوحة التحكم محمية بتسجيل دخول (Firebase Authentication) — لا يمكن لأي شخص التعديل بدون حساب.
- إضافة / تعديل / حذف المنتجات تنعكس مباشرة على المتجر (تحديث لحظي).
- إعدادات المتجر (الاسم، رقم واتساب، الوصف) محفوظة في Firestore وتنعكس على واجهة المتجر.
- زر لاستيراد 6 منتجات تجريبية دفعة واحدة عند البدء.
- سلة الشراء تبقى محفوظة محلياً في متصفح كل زائر (لا داعي لمشاركتها بين الأجهزة).

## خطوات الربط مع Firebase (مرة واحدة فقط)

### 1) إنشاء مشروع Firebase
1. ادخل إلى https://console.firebase.google.com
2. أنشئ مشروعاً جديداً (Add project).
3. من الصفحة الرئيسية للمشروع، اضغط على أيقونة الويب `</>` لإضافة تطبيق ويب، وسمّه أي اسم.
4. سينسخ لك Firebase كائن `firebaseConfig` — الصقه داخل ملف `firebase-config.js` بدلاً من القيم الحالية.

### 2) تفعيل قاعدة البيانات (Firestore)
1. من القائمة الجانبية: Build → Firestore Database → Create database.
2. اختر "Start in production mode" ثم اختر أقرب موقع خادم.
3. بعد الإنشاء، اذهب إلى تبويب **Rules** والصق القواعد التالية ثم Publish:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{productId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /settings/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

هذه القواعد تسمح لأي زائر بقراءة المنتجات (لعرضها في المتجر)، لكنها تمنع أي تعديل أو حذف إلا من شخص مسجّل دخوله (الأدمن).

### 3) تفعيل تسجيل الدخول (Authentication)
1. من القائمة الجانبية: Build → Authentication → Get started.
2. من تبويب Sign-in method، فعّل **Email/Password**.
3. من تبويب Users، اضغط Add user وأدخل بريدك الإلكتروني وكلمة مرور — هذا هو حساب دخولك للوحة التحكم.
   (يمكنك إضافة أكثر من مستخدم إذا كان أكثر من شخص يدير المتجر.)

### 4) رفع الملفات
ارفع كل الملفات (بعد تعديل `firebase-config.js`) إلى GitHub Pages كالمعتاد. افتح `admin.html`، سجّل دخولك بالبريد وكلمة المرور اللذين أنشأتهما، وابدأ بإضافة منتجاتك — ستظهر مباشرة في `index.html` لأي زائر ومن أي جهاز.

## ملاحظات مهمة
- **حجم الصور:** الصور تُحفظ داخل نص المستند في Firestore (Base64)، وحد المستند الواحد في Firestore هو 1MB، لذلك تم تحديد حد أقصى 500KB لملف الصورة قبل الرفع. لكميات كبيرة من الصور عالية الجودة يُفضّل مستقبلاً استخدام Firebase Storage بدلاً من هذا الأسلوب — أخبرني إن أردت هذا التطوير.
- **الخطة المجانية (Spark):** تكفي تماماً لمتجر صغير ومتوسط (حصة يومية سخية من القراءة/الكتابة).
- **الأمان:** لا تشارك بيانات `firebaseConfig` كسرّ — هي مخصصة للعمل من المتصفح، لكن الحماية الحقيقية تأتي من Firestore Rules وتسجيل الدخول، وكلاهما مفعّل هنا.
- إذا نسيت تعديل `firebase-config.js` فستبقى لوحة التحكم تعمل لكنها لن تتصل بقاعدة بيانات حقيقية (ستظهر رسالة خطأ اتصال).
