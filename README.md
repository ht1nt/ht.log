# متجر إلكتروني + لوحة تحكم

## الملفات
- `index.html` المتجر
- `admin.html` لوحة التحكم
- `style.css` تصميم المتجر
- `script.js` وظائف المتجر
- `admin.css` تصميم لوحة التحكم
- `admin.js` وظائف لوحة التحكم

## المزايا الجديدة
- إضافة / تعديل / حذف المنتجات.
- اسم المنتج، SKU، القسم، السعر، السعر القديم، المخزون، الشارة، الوصف.
- رفع صورة للمنتج من الهاتف أو الكمبيوتر.
- معاينة الصورة قبل الحفظ.
- بحث وتصفية داخل لوحة التحكم.
- إحصائيات عدد المنتجات والمخزون وقيمة المخزون.
- إعدادات اسم المتجر ورقم واتساب والوصف.
- المنتجات تظهر تلقائياً في واجهة المتجر.

## مهم جداً
هذه نسخة Static مناسبة لـ GitHub Pages. لوحة التحكم تحفظ البيانات في `localStorage` للمتصفح الحالي، لذلك:
- إذا فتحت الموقع من جهاز آخر لن ترى نفس المنتجات.
- إذا مسحت بيانات المتصفح قد تفقد البيانات.
- رفع الصور يحفظها داخل المتصفح، وليس على GitHub.

إذا أردت لوحة تحكم حقيقية مشتركة بين جميع الأجهزة، نحتاج Backend/قاعدة بيانات مثل Supabase أو Firebase، ويمكن تطوير النسخة لذلك لاحقاً.
